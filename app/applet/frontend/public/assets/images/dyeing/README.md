# Traditional Bodo Dyeing Image Directory

This directory stores high-resolution photographs documenting traditional Bodo handloom thread dyeing, natural colour extraction, and mordanting practices.

### Recommended File Naming Convention & Supported Subjects:

1. **Undyed Yarn & Raw Threads**:
   - `undyed-raw-yarn.jpg` / `.png` / `.webp`

2. **Yellow Turmeric-Dyed Yarn**:
   - `turmeric-yellow-yarn.jpg` / `.png` / `.webp`

3. **Natural Red & Reddish-Yellow Dyes**:
   - `madder-reddish-yarn.jpg` / `.png` / `.webp`
   - `reddish-yellow-dye.jpg` / `.png` / `.webp`

4. **Indigo & Blue-Dyed Yarn**:
   - `indigo-blue-yarn.jpg` / `.png` / `.webp`

5. **Green & Black Dyed Threads**:
   - `green-black-dyed-threads.jpg` / `.png` / `.webp`
   - `forest-green-yarn.jpg` / `.png` / `.webp`
   - `iron-black-yarn.jpg` / `.png` / `.webp`

6. **Natural Dye Sources (Barks, Leaves & Roots)**:
   - `dye-sources-barks-leaves-roots.jpg` / `.png` / `.webp`

7. **Alum (Fitkaari) & Mineral Mordants**:
   - `alum-fitkaari-mordant.jpg` / `.png` / `.webp`

8. **Traditional Dyeing Equipment, Vessels & Cauldrons**:
   - `traditional-dyeing-vessel.jpg` / `.png` / `.webp`

9. **Drying Yarn on Bamboo Racks & Finished Skeins**:
   - `drying-yarn-bamboo-racks.jpg` / `.png` / `.webp`

### Supported File Extensions:
`.jpg`, `.jpeg`, `.png`, `.webp`, `.JPG`

### Note on Browser Uploads:
Images uploaded through the Content Editor (`/editor` or the bottom-right Content Editor button) are safely stored in browser storage (`localStorage`) and can be exported as a full JSON backup. To permanently add photos to the source repository, deposit your image files into this `frontend/public/assets/images/dyeing/` directory with matching filenames.
