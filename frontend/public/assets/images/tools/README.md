# Handloom Tool Images
Photographs of indigenous Bodo weaving tools and implements.

Recommended files:
- `zenther.jpg` (Traditional roller cotton gin)
- `bobbin.jpg` (Bamboo bobbin / Khabang)
- `chwrkhi.jpg` (Yarn swift)
- `tharai.jpg` (Reed comb / Batten)
- `maku.jpg` (Carved weaving shuttle)

Subfolder:
- `other-tools/` for auxiliary workshop implements

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
